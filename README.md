## How to Run
1. Install [XAMPP](https://www.apachefriends.org/index.html) or a similar local server.
2. Clone this repository to your htdocs (or www) directory.
3. For each project, import its .sql database file into your local MySQL server (via phpMyAdmin).
4. Navigate to http://localhost/Web-Programming-Projects-CIT220/<Project-Folder-Name> in your browser.
